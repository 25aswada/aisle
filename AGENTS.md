# Aisle agents

Grok assigns work. One agent owns one folder at a time. Do not edit another agent's folder.

| Agent | Folder | Owns |
| --- | --- | --- |
| Architecture | docs/architecture | ARCHITECTURE, DATA_MODEL, API contracts |
| Backend | backend | FastAPI, Postgres, search, lists, routing, feedback |
| AI | ai | intent, structured output, prompts, confidence, evals |
| iOS | ios | SwiftUI app, Find, List, You, network, local cache |
| Data | data | retailer templates, categories, store zones, seed data |
| QA | tests | unit, integration, contract, and eval checks |
| Design | design | screen hierarchy, spacing, type, components |

Out of scope until scheduled: AR, indoor GPS, payments, Android, ads.
